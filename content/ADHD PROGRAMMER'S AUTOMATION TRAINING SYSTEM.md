# Instructions
## SYSTEM OVERVIEW

Transform conscious strategies into automatic responses through structured training that targets specific triggers and builds muscle memory for ADHD management techniques.

## PHASE 1: TRIGGER MAPPING & RESPONSE PROGRAMMING

### Core Trigger-Response Pairs

**Format: WHEN [somatic/mental trigger] → AUTOMATICALLY [response]**

#### Planning Triggers

- **Sunday 6 PM alarm** → Brain dump + weekly planning sequence
- **Wake up** → Daily check-in ritual (energy assessment + must-dos)
- **Calendar notification** → Environment setup check
- **End of work day** → Next-day preparation

#### Somatic Resistance Triggers

- **Pit-of-stomach disgust/fear sensation** → "This feeling means it's important" + 2-minute rule
- **Chest tightness when approaching task** → Three deep breaths + physical position change
- **Heavy/sluggish body feeling** → Physical reset (jumping jacks/stretch)
- **Jaw clenching or shoulder tension** → "Notice and release" + micro-break
- **Restless leg/fidgeting increase** → Switch to standing or walking task mode

#### Mental Resistance Triggers

- **Staring at screen for 30+ seconds** → "What's the smallest next thing?" mental query
- **Mind going blank** → Switch hands or draw concept instead
- **Overwhelm cascade thinking** → External brain dump + prioritize one item

#### Mid-Task Flow Maintenance Triggers

- **Notice I've stopped working** → "What's the smallest next thing I need to do?"
- **Hands pause on keyboard >10 seconds** → Micro-reorientation protocol
- **Eyes unfocus/zone out** → "Where am I? What's next?" + point to current line
- **Feel momentum slipping** → Narrate current state out loud
- **Multiple false starts** → "What specifically am I trying to accomplish right now?"

#### **Break Transition Management Triggers**

**Critical for preventing 2-hour "break" spirals**

##### Pre-Break Planning Triggers

- **Feel need for break** → "What am I breaking FROM and TO?" + set specific return cue
- **Mental fatigue sensation** → Break type selection (movement/rest/social/creative)
- **Reaching for phone/distraction** → "Is this a break or procrastination?" check
- **"Just one more thing" urge** → Pre-commit to return method before starting break

##### Break Boundary Triggers

- **Start any break activity** → Automatic timer set + return method chosen
- **Begin "light" cleaning/organizing** → "This is now my break activity" acknowledgment + timer check
- **Pick up phone/start podcast** → "15 minutes max" commitment + phone timer
- **Feel break activity getting engaging** → "This is the hook - check timer" awareness

##### Return-to-Work Transition Triggers

- **Timer goes off during break** → "What's the smallest next thing in my work?" + 2-minute commitment
- **Break activity feels "done"** → Immediate return preparation (close tabs, gather materials)
- **Resistance to returning** → "Just open the file/document" + 2-minute rule
- **"I'll just finish this one thing"** → "This is the trap" + immediate work file opening

##### Time Awareness Triggers

- **15 minutes into any break activity** → "How much longer for this?" + timer check
- **Engaging break activity** → "Future me will thank me for returning now" thought
- **Multiple break activities stacking** → "One break activity at a time" rule enforcement
- **Break extending past 30 minutes** → "This is now procrastination" acknowledgment + immediate return

#### Frustration Reframing Triggers

- **Anger/irritation surge** → "What pattern is this teaching me?"
- **Making repeated errors** → "How might I error next? How can I reduce this error type?"
- **Feeling "stupid" or "slow"** → "What system would help future me here?"
- **Urge to quit/give up** → "What would make this 10% easier?"
- **Perfectionism paralysis** → "Good enough for now, iterate later"

#### Focus Failure Triggers

- **Mind wandering 3+ times** → 15-minute work chunk reset
- **Reading same line twice** → Switch learning modality
- **Feeling stuck for 5+ minutes** → Voice memo recording
- **Energy drop sensation** → Activity-energy matching check


## PHASE 2: EMBODIED PRACTICE SCENARIOS

### Somatic Awareness Training (5-10 minutes daily)

**Building body-based trigger recognition:**

#### Daily Body Scan Drills

1. **Morning Baseline:** Notice current physical state before any tasks
2. **Pre-Task Check:** Scan stomach, chest, shoulders, jaw before starting work
3. **Mid-Task Monitoring:** Set random timers to notice physical state changes
4. **Resistance Mapping:** When feeling stuck, identify where you feel it in body

#### Artificial Resistance Creation

1. **Intentional Task Approach:** Set up a boring task, approach it slowly, notice stomach sensations
2. **Productive Hesitation:** Practice the pause between "I should do this" and stomach feeling
3. **Reframe Training:** Create frustrating scenarios (difficult math problems) and practice curiosity shift
4. **Error Embrace:** Intentionally make mistakes and practice reframing response

### **Break Transition Training Scenarios (10-15 minutes daily)**

**Building automatic break management responses:**

#### Break Boundary Training Drills

1. **Artificial Break Simulation:** Set timer for 5 minutes, start engaging activity (podcast/cleaning), practice stopping when timer goes off
2. **Hook Recognition:** Start engaging break activity, set timer for 10 minutes, practice noticing when activity becomes "sticky"
3. **Return Preparation:** Practice closing break activity mid-way through and returning to work immediately
4. **Multiple Activity Training:** Start one break activity, get urge to start another, practice "one break activity at a time" rule

#### Pre-Break Planning Practice

1. **Break Type Selection:** Feel fatigue, practice choosing between movement/rest/creative break based on energy level
2. **Timer Setting Automation:** Every time you feel need for break, practice automatic timer setting before starting activity
3. **Return Method Commitment:** Practice stating out loud "I will return by [specific method]" before each break
4. **Work Context Preservation:** Practice writing down "I was working on [specific thing]" before taking break

#### Break Extension Prevention Drills

1. **Engagement Interruption:** Start enjoyable break activity, set timer for 5 minutes, practice stopping when timer goes off even if activity is engaging
2. **"Just One More" Resistance:** Practice recognizing and stopping the "just one more thing" urge during breaks
3. **Procrastination Identification:** Practice distinguishing between "I need a break" and "I'm avoiding work"
4. **Immediate Return:** Practice returning to work the moment break timer goes off, even if break activity is unfinished

### **Relaxation State Management Training (15-20 minutes daily)**

**Building tolerance for genuine relaxation and longer-form content:**

#### Hypervigilance Recognition Training

1. **Coiled Spring Body Scan:** After completing daily tasks, practice identifying "wired but tired" physical sensations
2. **Dopamine Seeking Recognition:** Set up relaxing activity, notice urge for short-form content, practice identifying "this is dopamine seeking"
3. **Itching Feeling Mapping:** During calm activities, practice noticing and naming the "restless/itching" sensation without immediately acting on it
4. **Nervous System State Assessment:** Practice distinguishing between "I need stimulation" vs "I need to discharge energy" vs "I need to calm down"

#### Progressive Relaxation Building Drills

1. **10-Minute Tolerance Building:** Start with 10-minute commitment to longer content, practice sitting with restlessness without switching
2. **Phone Resistance Training:** Place phone in another room during relaxation, practice resisting urge to retrieve it
3. **Boredom Reframing:** When feeling "bored" during calm activity, practice reframe "boredom = nervous system calming down"
4. **Discharge Protocol Practice:** Practice 5-minute movement routine followed by attempt at stillness, building tolerance gradually

#### Relaxation Transition Protocols

1. **Task-to-Rest Transition:** Practice explicit transition ritual between completing work and beginning relaxation
2. **Entertainment Decision Tree:** Practice asking "What does my nervous system need right now?" before choosing entertainment
3. **Restlessness Management:** When feeling restless during TV/movie, practice 5-minute movement break then return to same content
4. **Attention Wandering Acceptance:** Practice noticing mind wandering during relaxation without judgment or immediate action

### **Weekly Planning Sustainability Training (20-30 minutes weekly)**

**Building realistic planning habits that don't lead to system abandonment:**

#### Overplanning Prevention Drills

1. **Three-Priority Rule Enforcement:** Practice weekly planning with strict 3-priority maximum, resist adding more
2. **Time Estimation Calibration:** Practice doubling initial time estimates for all tasks
3. **Excitement Regulation:** When feeling excited about new project, practice "Is this essential THIS week?" filter
4. **Planning Time Limits:** Set 30-minute timer for weekly planning, practice stopping when timer goes off regardless of completion

#### Reality Calibration Training

1. **Previous Week Analysis:** Practice honest assessment of what was actually accomplished vs. planned
2. **Capacity Reality Check:** Practice planning for only 70% of available time, leaving 30% buffer
3. **Energy Level Forecasting:** Practice considering energy patterns when planning (Monday energy vs. Friday energy)
4. **Optimism Bias Recognition:** Practice identifying when planning is based on "ideal conditions" vs. reality

#### Mid-Week Adjustment Protocols

1. **Tuesday Assessment Drill:** Practice mid-week check-in without judgment or plan abandonment
2. **Plan Modification Training:** Practice adjusting weekly plan when behind, focus on "adjust don't abandon"
3. **Emergency Simplification:** Practice rapid plan reduction when feeling overwhelmed mid-week
4. **Minimal Viable Planning:** When wanting to abandon system, practice identifying "what's the one thing I can keep?"

### Micro-Reorientation Training Scenarios

#### Flow State Interruption Drills

1. **Artificial Stops:** Set random timers during work, practice "What's smallest next thing?"
2. **Confusion Simulation:** Open random complex code/text, practice reorientation protocol
3. **Momentum Recovery:** Intentionally interrupt good work flow, practice getting back in
4. **Narrative Training:** Practice out-loud narration of current state and next steps

#### Frustration Transformation Practice

1. **Error Injection:** Create scenarios designed to produce specific error types
2. **Curiosity Pivoting:** Practice immediate shift from "this is wrong" to "what's the pattern?"
3. **System Building:** When hitting frustration, practice asking "what system would help future me?"
4. **Perspective Shifting:** Practice multiple reframes of same frustrating situation

### Simulated Practice Scenarios (5-10 minutes)

Create artificial situations to practice responses:

#### Resistance Training Drills

1. **Fake Task Setup:** Set up a boring task, feel resistance, practice 2-minute rule
2. **Position Change Drill:** Sit in "stuck" position, trigger automatic position change
3. **Timer Practice:** Set random timers throughout day, practice micro-break response

#### Focus Training Scenarios

1. **Distraction Injection:** Intentionally introduce distractions, practice refocus techniques
2. **Energy Matching:** Practice recognizing energy levels and matching tasks accordingly
3. **Break Transition:** Practice smooth transitions between work and break states

### Weekly Simulation Sessions (30 minutes)

#### Sunday Planning Simulation

- Set up scattered mental state artificially
- Practice entire weekly planning sequence
- Time the process, aim for automation

#### Mid-week Crisis Simulation

- Create artificial overwhelming situation
- Practice crisis management protocols
- Focus on automatic response activation

#### **Break Spiral Prevention Simulation**

- Set up situation where you "need a break"
- Practice entire break cycle: planning → execution → return
- Introduce artificial "hooks" (interesting podcast, cleaning task)
- Practice break boundary enforcement

## TROUBLESHOOTING AUTOMATION FAILURES

**When automatic responses break down:**

### Somatic Disconnection Issues

- **Can't feel stomach signals:** Practice daily body scans for 1 week
- **Reacting too late to resistance:** Lower threshold for "smallest feeling"
- **Ignoring early warning signs:** Set hourly body-state check alarms

### Reorientation Failures

- **Forgetting to ask "what's next?":** Set random timers with this phrase
- **Question doesn't help:** Experiment with alternatives: "What would progress look like?" "What's one tiny step?"
- **Getting lost in planning:** Time-box reorientation to 30 seconds max

### Reframing Difficulties

- **Stuck in frustration mode:** Practice physical reset first, then reframe
- **Reframes feel fake:** Start with "I notice I'm frustrated, what's the pattern here?"
- **Can't find curiosity:** Use "teaching future me" frame instead of curiosity

### **Break Transition Failures**

- **Can't stop break activities:** Practice stopping mid-activity for 1 week to build "stop" muscle
- **Break timer doesn't work:** Use phone alarm + physical timer placement in break area
- **Return resistance too strong:** Lower return commitment to 30 seconds of work
- **Keep extending "just 5 more minutes":** Implement "no negotiation" rule - timer means immediate return
- **Procrastination vs. break confusion:** Use body scan - genuine breaks feel restful, procrastination feels tense
- **Break activities become all-consuming:** Limit break activities to boring ones for 1 week to break habit

### **Relaxation State Management Failures**

- **Can't recognize "coiled spring" state:** Set hourly body scans for 1 week to build awareness
- **Keep reaching for short-form content automatically:** Remove access to meme apps for 1 week, practice tolerance building
- **Can't sit through movie/TV without switching:** Start with 10-minute commitments, gradually increase
- **Nervous system won't calm down:** Add 10-minute movement/discharge routine before attempting relaxation
- **"Boredom = need stimulation" assumption:** Practice reframe "boredom = nervous system healing" for 1 week
- **Evening relaxation impossible:** Add explicit work-to-rest transition ritual (5-minute walk, change clothes, etc.)

### **Weekly Planning System Failures**

- **Keep overplanning despite awareness:** Use timer-limited planning (20 minutes max) + friend accountability
- **Abandon plan mid-week when behind:** Practice "adjust don't abandon" - reduce scope but keep 1 priority
- **Time estimates consistently wrong:** Track actual vs. estimated for 2 weeks, then triple estimates instead of double
- **Excitement leads to scope creep:** Implement "new idea parking lot" - write down but don't add to current week
- **Planning feels overwhelming:** Reduce to 1 priority per week until system feels sustainable
- **Can't stick to 3-priority limit:** Use physical constraint - only 3 index cards allowed for weekly planning

### General Automation Breakdown

1. Return to conscious practice for 3 days
2. Identify what changed in the trigger/context/body state
3. Adjust response to new conditions
4. Re-train the modified response pattern
5. Test integration with existing automatic responses

### **Emergency Break Spiral Recovery Protocol**

**When you realize you've been in a break spiral for 1+ hours:**

1. **Immediate Stop:** Drop break activity exactly where it is, unfinished
2. **No Negotiation:** Don't "just finish this one thing"
3. **Physical Reset:** Stand up, take 3 deep breaths
4. **Work File Opening:** Open work file/document immediately
5. **2-Minute Rule:** Commit to just 2 minutes of work
6. **Pattern Analysis:** After work session, analyze what triggered the spiral
7. **System Adjustment:** Modify break protocols based on spiral trigger
